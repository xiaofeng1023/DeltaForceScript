#   必须改用 Paddle 官方源安装(按本机 CUDA 版本选 cu118 / cu126 / cu129 之一):
#     .\.venv\Scripts\python.exe -m pip uninstall -y paddlepaddle
#     .\.venv\Scripts\python.exe -m pip install paddlepaddle-gpu==3.2.1 -i https://www.paddlepaddle.org.cn/packages/stable/cu126/
#   源地址与 CUDA 对应关系见: https://www.paddlepaddle.org.cn/install/quick
# 说明: CPU 版(paddlepaddle)与 GPU 版(paddlepaddle-gpu)都提供 paddle 模块,
